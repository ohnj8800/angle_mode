## 判讀原則

- 角度位置模態：與低頻角度曲線高度相關。
- 角度狀態模態：10°與43°穩定期間的RMS不同。
- 角度移動模態：扣除事件前後局部狀態基準後仍增強。
- 目前僅有四次切換，結果仍應稱為候選頻帶，不應稱為異常或故障。
